pySpinW AI Policy
=================

We are open to contributions (PR or issue) that have employed LLMs, and
while these contributions remain of manageable quantity and quality
we will treat them the same as contributions generated entirely by humans.

However, for transparency, we ask that any code contribution that has employed an LLM
be tagged with "LLM Used", and that if an issue or PR summary has been created 
using and LLM be tagged with "AI Generated".

We also ask that 
1) AI agents do not participate in conversations on issues or pull requests, 
2) the human driving the LLM takes responsibility for contributions, including responding to comments 
3) that fully autonomous agents are not used.
